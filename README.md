## Course Overview

430 picks up where 330 left off and moves you to the other side of the request. You built
things that run in a browser. Now you build the servers those things talk to. Topics include:

- Node.js and server-side JavaScript
- HTTP, status codes, headers, and how the web actually moves data
- Building and consuming web APIs
- Databases and persistence
- Templating, MVC structure, and application architecture
- Deployment to a cloud host
- Some React on the front end
